# violin-onshape
# 3D Printed Violin Project

## Description
This project is a fully 3D-designed violin model created from scratch using Onshape CAD software. It replicates the traditional dimensions, geometry, and elegant curves of a classic violin while adapting the structural components to be optimized for modern desktop 3D printing methods. The model is divided into modular sections to allow for easy printing, assembly, and post-processing without requiring advanced industrial equipment.

## How it is used
Once the design is exported, the individual components are 3D printed using durable plastic filament (such as PLA or PETG). After printing, the pieces are aligned and securely bonded together using structural adhesive or internal reinforcement rods. Standard acoustic violin hardware—including a bridge, a tailpiece, tuning pegs, and a set of four strings—is then installed onto the assembled body. The instrument can then be tuned and used either as a functional acoustic display piece or an experimental musical instrument.

## Why I made this project
I chose to build this project to explore the intersection of classical instrument craftsmanship and digital manufacturing technology. Creating a functional stringed instrument in CAD presents unique engineering challenges, particularly in balancing aesthetic accuracy with the mechanical strength required to withstand string tension. This project serves as an open-source, accessible template to demonstrate how complex, organic shapes can be successfully modeled in cloud-based CAD platforms and shared with the global maker community.
